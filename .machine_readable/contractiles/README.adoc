= Contractiles: retired

Each contractile here (adjust, bust, dust, intend, must, trust) was an
`.a2ml` declaration with a Nickel runner and guard. The declarations were
template boilerplate. Most were `test -f` checks for other `.a2ml` files, and
none named this repository. They have been removed along with A2ML.

Repository checks run as `.k9` validators (`.machine_readable/self-validating/`,
`.githooks/validate-k9.sh`) and as CI workflows.

The last tree that held them: https://github.com/metadatastician/ZenodoDeposits.jl/tree/d2d4c2df2dcc5819ef7cfeb94d075db3acd242d3/.machine_readable/contractiles
