= Descriptiles: retired

The `.a2ml` descriptiles that used to live here (CLADE, META, ECOSYSTEM,
AGENTIC, NEUROSYM, PLAYBOOK, STATE, and `anchors/ANCHOR`) have been removed.
A2ML is retired across the estate.

Their facts now live in the repo deed at the repository root,
`ZenodoDeposits.jl_chora.deed`. It follows the deed grammar
(`hyperpolymath/standards`, `deed/spec/abnf/deed.abnf`) and passes
`deed_lint.py`. Checks live in `.k9` files.

The same change removed the machinery that read those files: the arrival-pack
generator for `CLAUDE.md`, the coaptation receipts, and the a2ml-paired
contractiles.

The last tree that held them: https://github.com/metadatastician/ZenodoDeposits.jl/tree/d2d4c2df2dcc5819ef7cfeb94d075db3acd242d3/.machine_readable
