= Bot directives: retired

The `.a2ml` bot directives (`methodology`, `coverage`, `debt`) have been
removed. They held template defaults with nothing specific to this repository.

Agent permissions and integrity rules are in the `agentic` section of
`ZenodoDeposits.jl_chora.deed`. Working notes for agents are in `CLAUDE.md`.

The last tree that held them: https://github.com/metadatastician/ZenodoDeposits.jl/tree/d2d4c2df2dcc5819ef7cfeb94d075db3acd242d3/.machine_readable/bot_directives
