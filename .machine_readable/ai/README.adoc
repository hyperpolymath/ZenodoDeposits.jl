= AI Guidance Directory

Put AI-facing instructions in this folder.

Examples:

* `CLAUDE.md`
* `COPILOT.md`
* `GEMINI.md`
* `AI.djot`

Avoid scattering agent instruction files around the repo root.

Recommended machine read order:

* `CLAUDE.md`
* `ZenodoDeposits.jl_chora.deed` (repo deed: identity, state, ecosystem, agent permissions, golden path)
