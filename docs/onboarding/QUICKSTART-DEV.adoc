== Contractile Invariants

Read `.machine_readable/MUST.contractile` before making changes.
Key invariants that must never be violated:

* Resuming the publication journal from any persisted state never creates a second deposition and never publishes twice (proved in `proofs/agda/`).
* A token is read only from the environment or `~/.netrc` and is never written to journal state or a bundle.
* The sandbox is the default; production requires an explicit `env=:production`.
