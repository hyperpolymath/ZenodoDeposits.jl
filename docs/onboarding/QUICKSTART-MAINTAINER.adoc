== Overview

This guide covers packaging, deploying, and maintaining rsr-template-repo for
distribution on your platform.

== Runtime Dependencies

HTTP, JSON3, MD5, SHA

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/ZenodoDeposits.jl.git
cd ZenodoDeposits.jl
julia --project -e "using Pkg; Pkg.instantiate(); Pkg.test()"
----

Output: none (a Julia package is loaded from source; there is no build artefact).

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t rsr-template-repo .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/ZenodoDeposits/`
| Data files, assets

| `$PREFIX/share/doc/ZenodoDeposits/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/ZenodoDeposits/config.toml`

Fallback: `$HOME/.config/ZenodoDeposits/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update ZenodoDeposits`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/ZenodoDeposits-instance1 --config=/etc/ZenodoDeposits/instance1.toml
just install --prefix=/opt/ZenodoDeposits-instance2 --config=/etc/ZenodoDeposits/instance2.toml
----

Each instance has isolated config, data, and logs.
