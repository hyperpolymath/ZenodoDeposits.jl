# AI Conventions (Authoritative Source)

All AI coding agents working in this repository MUST follow these rules.
Per-tool config files (.cursorrules, .clinerules, etc.) reference this document.

## Session Startup

1. Read `CLAUDE.md` FIRST.
2. Read the repo deed, `ZenodoDeposits.jl_chora.deed`, at the repository root:
   - `state` for current status, blockers and next actions;
   - `anchor` for canonical authority boundaries and the golden path;
   - `meta` for maintenance/audit sequencing and execution order (the three axes);
   - `agentic` for agent permissions and constraints.
3. Read `docs/governance/MAINTENANCE-CHECKLIST.adoc` for baseline controls.

## State Files

Repository state, metadata, anchor and agent policy live in one file, the repo
deed `ZenodoDeposits.jl_chora.deed`. Update the matching section there. Do not
create separate per-topic state or metadata files. Machine-checked invariants
are `.k9` files under `.machine_readable/self-validating/`.

## Banned Patterns

| Language | Banned                              | Reason                    |
|----------|-------------------------------------|---------------------------|
| Idris2   | `believe_me`, `assert_total`        | Unsound escape hatches    |
| Haskell  | `unsafeCoerce`, `unsafePerformIO`   | Breaks type safety        |
| OCaml    | `Obj.magic`, `Obj.repr`, `Obj.obj`  | Unsafe casting            |
| Coq      | `Admitted`                          | Unproven assumption       |
| Lean     | `sorry`                             | Unproven assumption       |
| Rust     | `transmute` (unless FFI + SAFETY:)  | Unsound reinterpret       |

## Banned Languages

| Banned              | Use Instead        |
|---------------------|--------------------|
| TypeScript          | ReScript           |
| Node.js / npm / bun | Deno               |
| Go                  | Rust               |
| Python              | Julia / Rust       |

## Container Standard

- Runtime: **Podman** (never Docker).
- File: **Containerfile** (never Dockerfile).
- Base images: `cgr.dev/chainguard/wolfi-base:latest` or `cgr.dev/chainguard/static:latest`.

## ABI/FFI Standard

- ABI definitions: **Idris2** with dependent types (`src/interface/Abi/`).
- FFI implementation: **Zig** with C ABI compatibility (`ffi/zig/`).
- Generated C headers: `generated/abi/`.

## Build System

Use `just` (Justfile) for all build, test, lint, and format tasks.
